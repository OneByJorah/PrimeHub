## What This Is

PrimeHub — AI/ML platform portal — model registry, experiment tracking, and collaborative MLOps workspace.

## Features

- **Model registry** — versioned model storage and discovery
- **Experiment tracking** — log and compare training runs
- **Collaborative workspace** — team MLOps environment
- **Self-hosted** — run your own ML platform
- **Dark theme** — data-science aesthetic
